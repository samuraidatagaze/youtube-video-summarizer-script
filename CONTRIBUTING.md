## 🚨 Symptoms of a Broken Summarizer

Before you run another summary, check whether your script suffers from any of these classic problems. Each one points to a specific fix this guide teaches.

| **Symptom** | **What It Really Means** | **Fix This Guide Teaches** |
|-------------|---------------------------|------------------------------|
| 😵 Summary misses key points | Truncated transcript | Chunking |
| 🐌 Script slow | Re-fetching | Cache |
| 🧊 Hallucinations | No source quotes | Cite timestamps |
| 🔥 Too long output | No length budget | Token limit |
| 📉 Order lost | No timestamps | Anchor notes |
| 🔇 No transcript | Auto-captions off | Fallback |

> **💡 Tip:** If the summary misses key points, you're truncating the transcript — chunk it and summarize each part before merging.

## 🚀 First 5 Minutes — Minimal Working Example

The fastest way to summarize one video.

**Step 1 — Fetch.** Get the transcript.

**Step 2 — Chunk.** Split by length.

**Step 3 — Prompt.** Ask per chunk.

**Step 4 — Merge.** Combine summaries.

**Step 5 — Timestamp.** Keep anchors.

> **💡 Tip:** Always keep timestamps in the chunks — they make the final summary navigable.
